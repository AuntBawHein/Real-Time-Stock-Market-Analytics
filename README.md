1. Introduction

I built a real-time stock tracking system using Microsoft Fabric, PySpark, and Yahoo Finance API to automatically collect, store, and visualize stock prices.

 Why is this important?
 
Stock prices change every second, and manually checking them is time-consuming.

Automating the process allows me to track stock trends effortlessly.

 Who will benefit from this project?
 
Investors – Can monitor stock market trends in real time.
Financial analysts – Can analyze price movements and trends.
Businesses – Can use stock market insights for financial decisions.

2. Objectives
The main goals of my project were:
To automate real-time stock price tracking.
To store stock prices safely for future analysis.
To visualize stock trends using graphs and charts.
By achieving these goals, I can understand stock market trends without manually checking prices.

3. Technology Stack Used
 
I used the following tools and technologies to build my system:

 Data Collection & Streaming
 
Yahoo Finance API – To collect live stock prices automatically.

Microsoft Fabric EventStream – To stream real-time stock price updates.

 Data Processing & Storage
 
Fabric Notebook (PySpark) – To process and clean stock data for analysis.

Microsoft Fabric Lakehouse – To store stock prices in a structured format.

Data Visualization
 
Matplotlib & Pandas – To create charts and visualize stock price trends.
